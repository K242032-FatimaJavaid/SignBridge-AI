# SignBridge AI — Project Documentation

This directory contains the official academic documentation for SignBridge AI, developed as part of the AL-2002 Artificial Intelligence Laboratory course at FAST-NUCES, Karachi Campus, Fall 2026.

The `docs` directory also contains the official PDF versions of the project proposal and final project report.

## Implemented Components

- **ASL to Speech:** Webcam-based sign recognition using MediaPipe and trained machine-learning models, with sentence formation and speech output.
- **Speech/Text to ASL:** Translation of supported English expressions into 3D animated avatar gestures.
- **Gemini AI Assistant:** Conversational AI functionality with locally configured API credentials.
